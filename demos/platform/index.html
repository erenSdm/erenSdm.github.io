Workflow

From clone to production in three steps.

STEP 0101

Connect your repo

Point COBALT at a Git repository. We detect your framework and wire up preview deploys on every push.

$ cobalt link
✔ detected  next@16
✔ branch    main → prod
STEP 0202

Write against the SDK

Import the type-safe client. Queries, storage, and vectors are one import away — no glue code, no config sprawl.

import { Cobalt }
  from "cobalt";
const db = cbt.sql;
STEP 0303

Ship to the edge

One command deploys to every region behind a global anycast address. Rollbacks and logs are there when you need them.

$ cobalt deploy
→ 34 regions · 2.1s
→ live: cobalt.sh/x
